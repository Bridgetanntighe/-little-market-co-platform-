# The Little Market Co.

Website for The Little Bloom Market — premium self-serve flower bar hire for London offices, events and brand activations.

## Local preview

```bash
npm install
npm run dev
```

## Enquiry form

Set `VITE_FORM_ENDPOINT` (and optionally `VITE_FORM_ACCESS_KEY`) before building so enquiries are delivered. See `.env.example`.

## Deploy

Pushes to `main` deploy via GitHub Pages Actions.
